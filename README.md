# コード工場

子どものプログラミング学習用。Python のコードから 2D の工場（Factorio 風）を組み立て、実行するとロボットが機械を順に動かして、for・if・配列などの動きを見せる。

- モックアップ: `index.html`（ブラウザで直接開ける単一ファイル。外部依存は Google Fonts のみ）
- 遊べるページ: https://milestone-corp.github.io/code-factory/ （GitHub Pages。main に push すると自動で更新される）

## 現在のモックアップ（v0）

コードと工場部品の対応:

| コード | 工場での見た目 |
|---|---|
| `x = 5` | 青い「しまう機」。計算した答えが黄色い品物になって、倉庫の「x」の木箱へ運ばれる（古い中身は捨てられる） |
| `nums = [3, 8, 1]` | 倉庫に番号つきの棚（配列） |
| 変数を読む（`total + n` など） | 箱の中身のコピーが品物として機械まで飛んでくる |
| `for` / `while` | オレンジの「くりかえしエリア」。`for` は棚のマスから品物を1つ取り出してループ変数の箱へ入れる。戻り口のベルトで門へ戻る |
| `if` / `elif` / `else` | 紫の六角形「分かれ道」。「はい」「いいえ」のベルトに分かれる |
| `print` | 緑の「出荷機」。木箱が倉庫の下の出荷口へ運ばれ、右の一覧に並ぶ |
| `append` | 棚の最後に値をつめる |

仕組み: 自作の小さな Python サブセット解釈器（字句解析 → 構文解析 → レイアウト → 1ステップずつ出来事を出すジェネレータ → Canvas でアニメーション）。出来事には「倉庫から読んだ値（reads）」と「倉庫へしまう値（writes）」が付き、倉庫の絵は品物が箱に届いた瞬間に更新する（実行中の変数とは別に表示用のモデルを持つ）。倉庫は工場キャンバスの右側に、スクロールしても見える位置で描く。

## 今後の方針（2026-09-29 検討）

目標は「どんなコードでも」ではなく、**入門〜中級の Python（関数・辞書・break まで）を専用部品でわかりやすく、それ以外は汎用の箱で止まらずに表示する**。

### 土台の置き換え

自作解釈器のままだと本物の Python と細部がずれるため、次の構成に変える。

1. Pyodide（ブラウザで動く本物の CPython）で実行する
2. Python 標準の `ast` モジュールで構造を分解し、工場の配置に変換する
3. `sys.settrace` などで「何行目を実行した」「変数がどう変わった」を記録し、ロボットの動きに変換する

### 構文ごとの見せ方案

| 種類 | 見せ方の案 | 難しさ |
|---|---|---|
| `break` / `continue` | くりかえしエリアからの近道ベルト | 易しい |
| 辞書（dict） | ラベルつきの引き出し棚 | 易しい |
| `input()` | 受付窓口で入力を待つ | 易しい |
| 関数（`def`） | 別の部屋の「サブ工場」。呼び出しでロボットが出張する | 中くらい |
| 内包表記 | 1台に詰めた小型工場。中を開いて見られる | 中くらい |
| 例外（`try` / `except`） | 非常ベルトで救護室へ | 中くらい |
| 再帰 | 同じサブ工場が何重にも重なる | 難しい |
| クラス・オブジェクト | 設計図から製品を作る組立ライン | 難しい |
| ライブラリ（`random`、`math` など） | 中を見せない「外注工場」 | 見せ方は簡単 |

### 本質的に難しい点

1. **変数を「箱」とたとえる限界**: `a = b` で同じ配列を2つの名前が指すと説明できない。倉庫の品物に名札をぶら下げる方式に変える必要がある
2. **大きなプログラム**: 部屋ごとの折りたたみ・ズーム・今動いている関数だけ表示
3. **何万回も回るループ**: 最初の数周だけ見せて残りは早送り
4. **Python 以外の言語**: 同じ考え方で作れるが言語ごとに作業が要る

### 進め方

1. 土台を Pyodide と実行記録に置き換える（この時点で全構文が「汎用の箱」付きで動く）
2. 関数（サブ工場）、break / continue、辞書
3. 名札方式の倉庫、大きなプログラム用の折りたたみ・ズーム
4. 再帰、クラス
