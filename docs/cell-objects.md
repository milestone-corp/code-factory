# 細胞の中の宇宙 — 描くオブジェクト一覧（案）

コード工場の次のテーマ。細胞の中を拡大すると、宇宙のように広い空間で、さまざまな役割のオブジェクトが仕事をしている。その様子を子ども向けに見せるため、まず「何を描くか」を決める。

## 前提

- **舞台はヒトの細胞（動物細胞）1つ**。植物の細胞・細菌はあとで足す（末尾の「あとで足すもの」）
- **大きさの差が10万倍以上ある**（細胞 20µm 〜 水の粒 0.3nm）ので、1枚の絵に縮尺どおりには描けない。**ズームの段（レベル0〜3）**に分けて、段ごとに主役を決める
- **呼び名**: 正式名に加えて、仕事がひと目でわかる呼び名をつける（コード工場の「しまう機」「出荷機」と同じ考え方）。正式名も小さく出して、教科書とつながるようにする
- **色**: 仕事の種類で色を分ける（コード工場の代入=青、print=緑 と同じ）

| 色 | 仕事の種類 |
|---|---|
| 青 | 設計図・情報（DNA、RNA） |
| 緑 | ものづくり（リボソーム、小胞体） |
| オレンジ | エネルギー（ミトコンドリア、ATP） |
| 紫 | 運ぶ・道（小胞、モーター、細胞骨格） |
| 赤 | 守る・片づける（細胞膜、リソソーム、プロテアソーム） |
| 灰 | 材料・小さな粒（水、ブドウ糖、イオン） |

## 「細胞が野球場だったら」ものさし

細胞（約20µm）を野球場（約200m）まで1000万倍に拡大すると、それぞれの大きさは次のくらいになる。画面のすみにこのものさしを出して、「宇宙のような広さ」を数字でも感じられるようにする。

| もの | 本当の大きさ | 1000万倍すると |
|---|---|---|
| 細胞 | 約20µm | 野球場（200m） |
| 核 | 約6µm | 60mのドーム |
| ミトコンドリア | 幅0.5〜1µm、長さ1〜数µm | バス〜電車1両 |
| 運び袋（小胞） | 約100nm | 大玉ころがしの玉（1m） |
| リボソーム | 約25nm | サッカーボール（25cm） |
| ふつうのタンパク質 | 3〜5nm | テニスボール（5cm） |
| DNAの太さ | 2nm | 2cmのひも |
| DNAの長さ（全部つなぐと） | 約2m | 2万km（地球半周）。それが60mのドームにしまわれている |
| 水の粒 | 0.3nm | 3mmの粒 |
| モーター（キネシン）の歩く速さ | 毎秒約0.8µm | 毎秒8m（短距離走の選手くらい） |

| 正式名 | 呼び名 | 仕事 | 見た目・動き | 優先 |
|---|---|---|---|---|

| 滑面小胞体 | 油と毒消しの工場 | 脂質を作る、毒を分解する | つぶつぶのない管の網 | △ |

## レベル2: 働き手（分子の段）

主役の段。1つ1つの働き手に「仕事中の動き」をつける。

| 正式名 | 呼び名 | 仕事 | 見た目・動き | 優先 |
|---|---|---|---|---|
| リボソーム | 組み立てロボット | mRNA を読みながら、アミノ酸をつないでタンパク質を作る | 大小2つの部品のだるま形。mRNA をはさんで進み、鎖を吐き出す | ◎ |
| tRNA | 材料の配達係 | 合うアミノ酸を1つずつリボソームへ届ける | L字形。頭にアミノ酸を1個のせて飛んでくる | ◎ |

| タンパク質 | 働き手そのもの | 鎖が折りたたまれて、決まった形になると仕事ができる | ビーズの鎖 → くしゃっと折りたたまれた塊 | ◎ |
| シャペロン | 折りたたみ係 | 失敗しそうなタンパク質を中にかくまって、正しく折りたたむ | ふたつきの樽 | △ |
| 輸送小胞 | 運び袋（宅配便） | ゴルジ体から細胞膜などへ荷物を運ぶ | 中に荷物の入った丸い袋 | ◎ |
| キネシン・ダイニン | 運び屋（モーター） | 微小管の上を2本足で歩いて、運び袋を引っぱる。キネシンは外向き、ダイニンは内向き | 2本足でとことこ歩く（1歩8nm、ATPを1個使って1歩） | ◎ |
| ミオシン | 引っぱり係 | アクチンの上を動いて、細胞の形を変えたり縮めたりする | アクチンを引っぱる腕 | △ |

| 受容体 | アンテナ（呼び鈴） | 外からの合図（ホルモンなど）を受けて中に伝える | 膜から外へ突き出たアンテナ | ○ |
| ユビキチン | 「すててOK」の荷札 | いらなくなったタンパク質につける目印 | 小さな札 | ○ |

## まず描くもの（v0）

「◎」のついたものを、次の2つのお話がつながるように描く。お話に出てこないものは最初は背景にも出さない。

1. **タンパク質ができて、届くまで**
   核で RNAポリメラーゼが DNA を mRNA に写す → mRNA が核膜孔から出る → 小胞体のリボソームに tRNA がアミノ酸を届けて鎖ができる → 折りたたまれてタンパク質になる → ゴルジ体で運び袋に詰める → キネシンが微小管を歩いて細胞膜まで運ぶ → 外へ出す
2. **エネルギーの流れ**
   ブドウ糖と酸素がミトコンドリアに入る → ATP合成酵素が回って ATP を充電 → キネシンが1歩ごとに ATP を1個使う（からの ADP が発電所に戻る）→ 二酸化炭素が外へ

この2つは「キネシンが ATP を使って荷物を運ぶ」場面で交わるので、1つの画面で両方の流れが見える。

## 子ども向けでも、うそにしないこと

- **細胞の中は、実はぎゅうぎゅう**。宇宙のようにがらんとしているのではなく、満員電車くらい混んでいる。「広い」のは大きさの比べ方の話で、レベル2・3では粒をたくさん描いて混み具合も見せる。広さ（ものさし）と混み具合の両方を出す
- **ほとんどの分子は、目的地をめざして泳いでいない**。水の粒にぶつかって、でたらめにゆれ動き（ブラウン運動）、たまたま相手に出会う。まっすぐ目的地へ向かうのは、レールの上を歩くモーター（キネシンなど）だけ。動きの描き分けで伝える
- **ミトコンドリアはエネルギーを「生む」のではなく「電池（ATP）に詰めかえる」**。燃料はブドウ糖
- **DNA は核から出ない**。外へ出るのはコピー（mRNA）
- **速さ**: 実際はとても速い（リボソームは1秒に数個のアミノ酸をつなぐ、ATP合成酵素は1秒に100回以上回る）。画面ではゆっくり再生し、「本当は○倍速い」と表示する（コード工場の「はやさ」スライダーと同じ扱い）
- 大きさ・数・速さの数字は概数。表示するときは「だいたい」「約」をつける

## あとで足すもの

- 植物の細胞: 葉緑体（太陽の光で糖を作る工場）、細胞壁（かたい外壁）、液胞（水と物の貯蔵タンク）
- 細菌: 核がない、べん毛（スクリュー）
- 細胞分裂: 中心体・紡錘体・染色体が並んで分かれる場面

## 決めること

1. 舞台を特定の細胞（たとえば神経細胞・筋肉の細胞）にするか、教科書どおりの「ふつうの動物細胞」にするか
2. 「宇宙」の見せ方をどこまで強めるか（背景を星空のように暗くする／小器官を惑星風に描く、など）。呼び名は仕事に合わせた「発電所」「運び屋」などにしているので、宇宙は見た目と広さの演出にとどめる案
3. コード工場と同じ単一 HTML ＋ Canvas で作るか、ズームの多い3D表現（WebGL）にするか
